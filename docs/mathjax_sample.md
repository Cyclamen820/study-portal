# 執筆者向け：TeX・化学式 記述チートシート

本サイトでは、MathJaxおよびmhchemパッケージを利用して、Markdownファイル内に美しい数式や化学式を直接記述することができます。

## 1. 基本ルール（インラインとブロック）

* **インライン表示**: 文章の中に数式を埋め込む場合は `$` で囲みます。
  
  * 入力: `時間 $t$ における濃度は〜`
  
  * 出力: 時間 $t$ における濃度は〜

* **ブロック（独立行）表示**: 中央揃えで大きく数式を表示する場合は `$$` で囲みます。

  * 入力: `$$y = ax + b$$`

  * 出力: （独立した行に $y = ax + b$ と表示されます）

## 2. よく使う数式記号と表現

### 分数
`\frac{分子}{分母}` を使用します。

* 入力: `$\frac{dx}{dt}$`

* 出力: $\frac{dx}{dt}$

### 上付き・下付き文字
上付きは `^`、下付きは `_` を使用します。複数文字の場合は `{}` で囲みます。

* 入力: `$x_1$`, `$e^{-kt}$`

* 出力: $x_1$, $e^{-kt}$

### ギリシャ文字
`\` から始まる英語の読み方で入力します。先頭を大文字にすると大文字になります。

* 入力: `$\tau$`, `$\alpha$`, `$\Delta$`

* 出力: $\tau$, $\alpha$, $\Delta$

### 対数（自然対数）
単に `ln` と書くと斜体（変数）になってしまうため、`\ln` と記述します。

* 入力: `$\ln V = -kt + \ln V_0$`

* 出力: $\ln V = -kt + \ln V_0$

### 大きなカッコ
分数など高さのある数式をカッコで囲む場合は、単なる `()` ではなく `\left(` と `\right)` を使うと、中身に合わせてカッコが自動で拡大されます。

* 入力: `$\ln \left( \frac{V_0}{V} \right)$`

* 出力: $\ln \left( \frac{V_0}{V} \right)$

## 3. 物理化学・反応速度論で頻出の数式モデル

**■ 微分速度式**

* 入力: `$$-\frac{d[A]}{dt} = k[A]$$`

* 出力: 

$$-\frac{d[A]}{dt} = k[A]$$

**■ アレニウスの式**

* 入力: `$$k = A \exp\left( -\frac{E_a}{RT} \right)$$`

* 出力: 

$$k = A \exp\left( -\frac{E_a}{RT} \right)$$

## 4. 化学式の書き方（mhchemの活用）

本サイトは化学式描画拡張 `mhchem` を導入しているため、数式モード内で `\ce{}` を使うことで、イタリック解除や下付き文字の指定を自動で行ってくれます。

### 基本的な化学種
数字は自動的に下付き文字として処理されます。

* 入力: `$\ce{H2O2}$`, `$\ce{KMnO4}$`

* 出力: $\ce{H2O2}$, $\ce{KMnO4}$

### イオン（電荷）

`^` を書かなくても、末尾の `+` や `-` を認識して自動で上付きにしてくれます（明示的に `^` を書いてもOKです）。

* 入力: `$\ce{Fe^{3+}}$`, `$\ce{Mn^2+}$`

* 出力: $\ce{Fe^{3+}}$, $\ce{Mn^{2+}}$

### 化学反応式と触媒（矢印の上の文字）

矢印 `->` を使うと反応式になり、`->[上に乗せる文字]` と書くことで触媒や反応条件を指定できます。

* 入力: `$$\ce{2H2O2 ->[Fe^{3+}] 2H2O + O2}$$`

* 出力: 

$$\ce{2H2O2 ->[Fe^{3+}] 2H2O + O2}$$
